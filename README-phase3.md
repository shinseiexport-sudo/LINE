# フェーズ3（予約管理）— 更新内容と入れ替え手順

## 何が増えるか

- 管理画面に「**⑤ 予約管理**」タブが追加されます
- 電話などで受けた予約を**店舗ごと**に登録し、状態を「予約済み → 来店済み／キャンセル／無断キャンセル」で管理します
- Reservationsシートは自動で使われます（初回アクセス時にヘッダーが無ければ整えます）

## 入れ替えるファイル（6つ）

GASエディタで、下のファイルの中身を**それぞれ同じ名前のファイルに上書き貼り付け**してください。

| ファイル | 新規/更新 |
|---|---|
| `ReservationService.gs` | **新規**（予約の登録・一覧・状態変更・削除） |
| `Config.gs` | 更新（バージョン0.3.0／予約ステータス定義） |
| `Bootstrap.gs` | 更新（予約日時・電話番号列を文字列書式に） |
| `Index.html` | 更新（⑤タブとフォーム追加） |
| `Script.html` | 更新（予約の表示・操作ロジック） |
| `Styles.html` | 更新（状態バッジの色・フィルター行） |

**手順:**

1. 各ファイルを上書き貼り付け（Ctrl+Sで保存。HexEditorの全保存でもOK）
2. **デプロイ → デプロイを管理 → 管理画面用（自分のみ）→ 編集 → バージョン: 新しいバージョン → デプロイ**（管理画面に反映）
3. 念のため **Webhook用（全員）も同じ要領で再デプロイ**（コードは共通なので、ずれを防ぐため）
4. 管理画面を **Ctrl+F5** →「⑤ 予約管理」タブが表示されればOK

## 使い方

1. 「＋ 予約を登録」→ 店舗を選び、名前・日時・人数を入力して保存
   - 「顧客（台帳から選ぶ）」で友だちを選ぶと、お名前が自動入力され、顧客ID（CU****）が予約に紐づきます
   - 電話のefore予約など台帳にいない客は「（台帳から選ばない）」のままでOK
2. 一覧は開いた時点の「今日」が表示されます。日付・店舗・状態で絞り込み
3. 当日来店したら「来店済み」、来なかったら「無断」、キャンセルなら「キャンセル」
   - 「予約済みへ戻す」でいつでもやり直せます
4. 「削除」は履歴ごと消えます。基本は「キャンセル」を使ってください

## 注意

- **Webhook用デプロイ（全員）のURLを開くと管理画面が見える**作りになっています。URLは長くて推測困難ですが、気になる場合は管理画面用（自分のみ）のURLだけをブックマークして使ってください。次の更新で「オーナー以外は画面を出さない」ガードを入れます
- 予約データはReservationsシートに蓄積されます。フェーズ4（注文受付）ではこの「状態管理」の型をそのまま使います
